How it works

Keep ownership where it belongs.

Connect a supported server

Use the official sign-in or server connection flow for Plex, Emby or Jellyfin.

Select its libraries

ARVIO reads the libraries and titles available to the authenticated server user.

Choose a playable version

Open a title and select from the media versions the server reports for that item.

No library migration

Adding a home server to ARVIO does not copy files, create another media library or bypass server permissions. The original Plex, Emby or Jellyfin server remains the source of truth and must be reachable for browsing and playback.

Common questions

Home server FAQ

Can ARVIO connect to Plex, Emby and Jellyfin at the same time?

Yes. Supported home servers can be connected to the same ARVIO profile and opened as separate library sources.

Does ARVIO merge or alter the server libraries?

No. Each server remains authoritative. ARVIO presents permitted libraries in a consistent interface without moving or changing the underlying media.

Why might a title have more than one source?

A server can expose multiple files or media versions for a title. ARVIO can list those versions so you can choose the appropriate resolution or encode.
